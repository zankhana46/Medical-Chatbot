# Swasthya Chatbot

A Streamlit application for interacting with a medical-domain AI assistant, powered by Google's Gemini models.

## Overview

**Swasthya Chatbot** lets users have text-based medical conversations and interpret medical images through a simple Streamlit interface. It uses Google's Gemini API for both text and vision responses.

> ⚠️ **Disclaimer:** This app is a personal/educational project. Responses are generated by a general-purpose LLM and are **not** a substitute for professional medical advice, diagnosis, or treatment.

## Features

- **DocBot** — Text-based medical Q&A. Ask health-related questions and get conversational responses from Gemini-Pro, with chat history preserved across the session.
- **VisionBot** — Upload an image along with a text prompt, and get an interpretation/description back from Gemini-1.5-Flash (multimodal image + text input).

> **Note:** An earlier version of this README referenced a "Chat with Report" feature for querying uploaded PDF medical reports. That feature is not currently active in the app (the code is present but commented out) and is planned for a future update.

## Tech Stack

- Python
- Streamlit (UI)
- Google Generative AI SDK (`google-generativeai`) — Gemini-Pro (text) and Gemini-1.5-Flash (vision)
- Pillow (image handling)
- streamlit-option-menu (sidebar navigation)
- python-dotenv (environment variable management)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/zankhana46/Medical-Chatbot.git
   cd Medical-Chatbot
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Set up environment variables:
   Create a `.env` file in the root directory and add your Google API key:
   ```bash
   GOOGLE_API_KEY=your_google_api_key
   ```

## Usage

1. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```

2. Use the sidebar to choose between **DocBot** and **VisionBot**.
   - **DocBot**: Type a medical question into the chat input and get a conversational response.
   - **VisionBot**: Upload an image, enter a prompt describing what you'd like to know, and click "Get Response."
